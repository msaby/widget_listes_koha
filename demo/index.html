Sélections documentaires

Explorez les sélections des bibliothèques. Chaque document ouvre sa notice dans le catalogue, dans un nouvel onglet.

Cette démonstration utilise les listes 11 et 32 du CSV fourni. Chaque exemple propose son code HTML et un exercice pour essayer ses contrôles.

Démarrer et intégrer la démonstration

Depuis la racine du dépôt, avec Python 3.10+ et Node.js 22+ :

python -m pip install -r requirements.txt
python scripts/csv_to_json.py --skip-covers
npm start

Ouvrir http://127.0.0.1:4173/demo/index.html. Arrêter le serveur avec Ctrl+C. Le JSON et les Excel doivent être générés avant de consulter les exemples. Avec --skip-covers, les emplacements de couverture restent vides.

Charger le composant une seule fois dans la page hôte, puis reprendre le code d'un exemple. Les chemins ci-dessous supposent les dossiers widget/ et data/ à la racine du site :

<script type="module" src="/widget/koha-list-widget.js"></script>
<link rel="stylesheet" href="/widget/koha-list-widget-custom.css">
<!-- Facultatif, pour Matomo configuré par le site hôte : -->
<script src="/widget/koha-list-widget-matomo.js" defer></script>

Le guide complet du dépôt se trouve dans docs/UTILISATION.md : publication, mise à jour quotidienne, options, personnalisation et dépannage.

À parcourir

Sans défilement automatique. Essayez les flèches, la recherche et le bouton de repli. Au clavier, utilisez Tab, puis Gauche/Droite ou Début/Fin dans les documents.

En grille

Six documents par page, triés par titre. Changez de page en haut puis en bas : les deux paginations restent synchronisées.

En liste

Les publications les plus récentes apparaissent d'abord. Recherchez un mot, puis téléchargez l'Excel : il conserve toute la liste.

Vue compacte

Une ligne par document, sans couverture. Réduisez la fenêtre pour observer la troncature visuelle ; les textes complets restent accessibles.

Défilement automatique

Délai par défaut : cinq secondes, sans export Excel. Éloignez le pointeur et le focus pour observer le mouvement, puis essayez Pause/Reprendre. La préférence système de réduction des mouvements désactive l'autoplay.

Défilement rapide, sélection repliée

Dépliez la sélection pour essayer le délai de 1 000 ms. Quittez ensuite le widget avec le pointeur et le clavier pour laisser le défilement reprendre.
